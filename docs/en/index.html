FROM DOWNLOAD TO GAME TIME

Three simple steps.

  1. 1

    Unpack everything

    Download the ZIP and extract all files to a regular folder. No installation is needed. Everything required is included.

  2. 2

    Open Start.cmd

    The program opens in your browser. Steam must be installed and your library available on the computer.

  3. 3

    Let chance choose

    Press «Выбрать игру» (Choose a game), then «Играть в Steam» (Play in Steam). Nothing launches or installs automatically.

Closing the tab does not stop the program. Open Stop.cmd to stop it completely.

GOOD TO KNOW

Before you begin.

Can I use it directly on this website?

No. A normal website cannot read the games installed on your computer. This page provides a demo and downloads. The actual randomizer runs locally and opens its own page in your browser.

What do I need to run it?

Windows 10/11 x64 (Intel or AMD), Steam and a modern browser. No administrator rights, separate Node.js installation or Codex are required. The layout works in narrow windows, but this is not a mobile app. The program's interface is currently in Russian; this website is available in English and Russian.

Where do uninstalled games and their sizes come from?

The list comes from Steam's local license cache, not the entire store. After a purchase or account change, open Steam online and refresh the list in Play Next.

«Место» means required disk space from Steam, not the exact download size. «≈» means an approximate local fallback. Missing information is shown as unknown. You can hide sizes and badges in Settings.

What is sent to the internet?

The program reads Steam files without modifying them. Account data, licenses, paths and exclusions are not sent. Storage lookups send public game IDs to Steam Store; Steam can see your IP address. Turn sizes off to stop new requests.

This website has no analytics, external fonts or access to your local program. GitHub, as the website host, receives visitors' normal web requests.

How do I update without losing exclusions?

Stop the program using Stop.cmd. Keep the data folder next to Start.cmd when updating: it contains exclusions, display settings and cached sizes. Pick history and some filters are tied to your browser and local address.

Send friends the clean release ZIP, not a copy of a used program folder, which may already contain personal settings.

How can I check the download?

Download releases from this repository. The program is not digitally signed. SHA-256 checks that your file matches the published archive, but does not replace a security review.
