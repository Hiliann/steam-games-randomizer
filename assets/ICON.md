# Play Next application icon

The icon combines a lime die and a play triangle on a charcoal rounded tile.
Created using the built-in image generation tool, with transparent background.
Source: `app-icon-source.png`. Windows and UI files are produced by
`scripts/build-icon.ps1`: `public/icon.ico` and `public/icon.png`.
The ICO contains 16, 24, 32, 48, 64, 128 and 256 pixel frames. Small frames use
32-bit DIBs plus transparency masks; the 256 pixel frame uses an RGBA PNG.
Copies in `docs` use the same artwork. Native builds embed the ICO directly.

## Generation prompt

Create one finished professional desktop application icon for Play Next, a Steam game library randomizer. Square composition, transparent background outside the icon. A bold rounded-square dark charcoal tile with smoothly rounded corners, inside it one large vivid lime green rounded die, rotated very slightly clockwise, with a clearly legible charcoal right-pointing play triangle cut into its center and two simple charcoal round die dots on opposite corners. Unified simple geometry, strong readable silhouette at 16 and 32 pixels, balanced substantial proportions. The lime die is the dominant form, not a small detail. A very subtle refined dimensional edge on the dark tile, but mostly flat clean vector-like surfaces with crisp edges, no photographic texture. Restrained dark charcoal #151b19 and fresh lime #c4ef80, small cool teal edge highlight allowed. Large icon almost fills the canvas with a small transparent safety margin. This is a production app icon, not a scene, not a mockup and not multiple variants. No text, letters, numbers, Steam logo, controller, starbursts, outlines around the canvas, extra background, watermark or drop shadow outside the tile. Show only the single complete centered app icon.
